# Architecture rules (detail)

- Every repo has `doc/architecture/` with `overview.md`, `structural-design.md`,
  `behavioural-design.md`, and an `adr/` log.
- ADR format: Context / Decision / Consequences, one file `NNNN-title.md`, plus `adr/README.md` index.
- Record a new ADR for: breaking changes, a new node type, protocol/transport decisions,
  and any non-obvious trade-off.
